# DetonaTV

## Instalar

- [Baixar para Windows](https://github.com/DetonadosPro/detonatv-releases/releases/latest/download/DetonaTV-Windows-Setup.exe)
- [Baixar para Android](https://github.com/DetonadosPro/detonatv-releases/releases/latest/download/DetonaTV-Android.apk)
- [Notas da última versão](https://github.com/DetonadosPro/detonatv-releases/releases/latest)

Esses links sempre entregam a versão mais recente. Para manter seus dados, instale por cima da versão existente.

## Atualizar

A partir da versão 0.8.1, Windows e Android avisam quando há uma nova versão e oferecem o botão **Atualizar**. A consulta também está em **Configurações → Atualizações**.

No Android, permita a instalação pelo DetonaTV e confirme a atualização na tela do sistema. Pode ser necessário tocar em Atualizar novamente depois de conceder a permissão.

Os pacotes são verificados antes de instalar. As atualizações preservam os dados locais; não desinstale o aplicativo.

## Samsung TV

A versão Tizen atual continua sendo 0.3.3. A distribuição pela loja Samsung ainda depende do cadastro no TV Seller Office e da aprovação do aplicativo.

Este repositório distribui os instaladores. Não contém listas, credenciais ou o código privado do serviço. Arquivos de verificação acompanham cada lançamento.
